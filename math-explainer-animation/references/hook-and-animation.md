# 前五秒与解释性动画

目标是让观众尽早看见“对象正在发生什么、为什么值得继续看”，不是承诺流量。先画出问题，再展示规则，结尾回答同一个问题。

## 设计两三个开头，再选一个

每个候选写出：第0秒对象、前5秒可见变化、观众会问的问题、后文如何兑现、隐藏了什么必要条件。可以用选择、对比、冲突、可验证预测或反直觉变化；不要把一种开头套到所有题目。

| 评价项 | 可执行的判断 |
| --- | --- |
| 相关性 | 去掉标题后，动作是否仍与本期数学问题有关？ |
| 可读性 | 手机上能看清对象、选择及必要条件吗？ |
| 解释收益 | 后文的数学能解决这个疑问，还是只借热点引流？ |
| 真实性 | 是否暗示未建模的胜率、实测效果或唯一答案？ |
| 动画潜力 | 对象能连续变形、移动、连接，还是只能换文字卡？ |

按每项0–2分作内部比较即可，不把分数伪装成播放率预测。选可兑现、条件清楚的候选。用户不喜欢天气时，应换有趣且能解释的对象，不只换一套天气图标。

## 每镜回答三个问题

1. 观众此刻需要理解什么？
2. 哪个图形变化实际承担解释？
3. 字幕只补充哪些不可缺少的条件或结论？

先对象、后关系、再规律。字幕和图形说同一件事。避免以文字淡入淡出承担主要讲解；不把文章压成快速字幕。

## 连续身份与因果

- 给同一对象稳定的 ID、颜色、形状和标签；不能只靠颜色辨别。
- 抽走一张牌应从“当前”区域移到“过去”区域，而不是瞬间变成另一张牌。
- 相同状态可以汇合，汇合前先让观众看到为什么相同。
- 分支先建立起点与箭头，再放结果和概率；概率条与计算同源。
- 状态变化完成后再显示总结，给关键结论停顿；不是每帧都要动。

“帅酷”优先通过有目的的动作实现：快速推入后刹停、沿因果方向连线、比较对象分流、相同对象归位、镜头小幅推进。局部光、尾迹、描边和短音只标记重要动作。主标题、限定与字幕保持稳定，不跟桌面镜头缩放。不加无关粒子、伪数据、科幻界面或复杂3D来填空。

## 从熟悉情境进入模型：掼蛋案例

熟悉的牌局能提出“应该记住什么”，却不能直接给出马尔可夫模型。真实对手手牌未知，玩家出牌也不是均匀抽签。

桥梁分三步：

1. 用自设牌局说明，历史记录能排除某些可能，单看本人手牌未必足够。
2. 明说“现在换个明牌实验”；更换标签和规则，展示所有初始牌。
3. 给出完整状态和转移规则，再讨论相同当前状态的下一步分布。

两条过去 A→Q 和 Q→A 都剩 K、3；等概率抽取规则下，下一步抽走 K 或3各一半。这个50%不是胜率，不能贴回未知的对手牌。具体数学见 `guandan-case.md`。

## 手机阅读与关键帧

默认1080×1920、30fps。字幕通常1–2行完整中文，先在约390像素宽的预览中看；字号不是安全保证，仍须检查实际编码画面。必要信息留边，按发布平台界面预留底部与侧边空间。横屏或配音等用户新要求优先。

每镜至少检查起点、关键变化前后、字幕切换前后和结尾。运动轨迹要查中途，不只查落点：牌面可能在弧线中擦过历史牌，概率可能先于对象出现。关键结论出现后留够阅读时间，不为卡点提前消失。

首轮只做10–15秒且含知识演示。交付可播放样片后停止，等待确认。确认后按新场景推进，同时检查上一段末尾与新段开头的连接。已确认片段记录版本与哈希；若优化影响它，先说明影响，再按用户授权修改并重新验收。
