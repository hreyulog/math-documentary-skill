# 案例：从掼蛋记牌进入马尔可夫性质

此文是已经完成的39秒教学样片的制作复盘，不附原片、音乐、私人会话或本机路径。它说明如何从熟悉问题搭桥到严格的玩具模型；不是固定选题模板，也不是实战策略。

## 为什么换开头

最初的天气分支虽清楚，吸引力不足。新开头直接显示本人K、3和对手一张未知牌，问“这张K敢出吗？”牌面先出现，动作推动问题，不用人物照片或Logo铺垫。画面明确标注自设教学情境。

回看公开记录，两张大王都已打出，只能排除对手再持有大王，不能保证普通K安全。本例采用的基本规则来源是[合肥工业大学2022年赛事通知附录](https://wgyxy.hfut.edu.cn/2022/1213/c6444a287644/page.htm)，不是声称核对了所有地区和平台细则。

## 39秒实际结构

| 区间 | 动画承担的解释 |
| --- | --- |
| 0–3秒 | K推向桌面后刹停；未知对手牌保持背面，建立选择 |
| 3–7.2秒 | 扫描旧记录，两张实体大王先后翻入，计数随核对完成增加 |
| 7.2–12.6秒 | `2−2=0`排除大王，再保留其他能压K的可能；不宣称最优动作 |
| 12.6–18秒 | 手牌、记录、余牌数归入信息框；说明本人手牌不等于全部信息 |
| 18–21.5秒 | 明确更换为四张全部可见的抽取实验，先显示A/Q/K/3，再显示每张25% |
| 21.5–27.5秒 | 两种过去A→Q与Q→A按不同顺序移走牌，都剩K、3 |
| 27.5–33秒 | 相同剩牌汇合；抽走K或3各50%，分别到只剩3或只剩K |
| 33–39秒 | 图形保持六秒，字幕给出带条件的马尔可夫性质 |

持续标注“明牌实验 · 等概率抽走一张 · 非实战规则”。真实掼蛋中对手未明牌，行动有策略，不能把实验50%称为真实胜率。39秒后的内容只是后续脚本计划，不算已经完成。

## 数学如何成为唯一数据源

初始牌集 `{A,Q,K,3}`，当前状态为**全部剩牌集合**。每一步从剩牌中均匀移除一张；空集设为吸收状态。非空状态有n张牌时，每个可抽对象概率为1/n。

```text
A→Q：{A,Q,K,3} → {Q,K,3} → {K,3}
Q→A：{A,Q,K,3} → {A,K,3} → {K,3}
共同预测：抽走K，概率1/2，下一状态{3}
          抽走3，概率1/2，下一状态{K}
```

两条历史本身各为 `1/4 × 1/3 = 1/12`，和下一步条件概率1/2不同。案例没有随机模拟，也不使用真实牌谱数据。计算模块枚举16个子集状态和65条合法有序历史，检查概率和、合法移除、空集吸收、路径质量、输入不变性和同状态同预测。有限穷举验证的是这个自设实验，不是证明真实掼蛋满足该性质。

定义依据见 `research-and-math.md` 中MIT课程与Dartmouth教材；具体牌集和示例由项目自行设计。

## 两次看图后修复

- **运动中碰撞**：K最后归位的弧线在12.6秒附近擦过历史大王边缘。只看起点和终点发现不了；调整中间控制点，让牌身份始终清楚，不靠闪烁掩盖。
- **标签抢先**：25%在四张牌全部展开前出现，规则对应对象还没站稳。改成四牌到齐后再显示概率，恢复“对象→关系→结论”的顺序。

风格加强采用推牌刹停、记录扫描、实体翻牌、不同轨迹归位和轻微桌面镜头推进；字幕与限定保持固定。帅酷来自动作表达信息，而不是装饰数量。
