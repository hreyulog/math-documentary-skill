# 数学动画首段工程

这个最小工程只注册 **15 秒样片**，不自动制作整期视频。默认 1080×1920、30fps。它演示一个人为设定的明牌实验：当前剩 K 和 3，每次等概率抽走一张，因此两种下一状态各占 50%。这不是实际掼蛋规则，也不是胜率。

## 运行

需要 Node.js 22+ 和 pnpm 10。首次在项目目录运行：

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm studio
pnpm render:preview
```

输出 `output/preview/math-preview-15s.mp4`、`output/preview/keyframes/*.png` 和 `qa/*.json`。仅渲染关键帧用 `pnpm stills`。输出目录不应提交 Git。

Windows 优先发现已安装的 Chrome；也可通过环境变量 `REMOTION_BROWSER_EXECUTABLE` 指定浏览器。其他系统默认使用 Remotion 管理的浏览器。管理浏览器无法启动时，先指定本机 Chrome，再重复渲染，不要把未完成的渲染报告成成片。

## 修改位置

- `src/config/series.json`：主题、`portrait` / `landscape`、账号名与本地音乐。账号名默认空，不生成固定水印。
- `src/math/card-removal.ts`：统一数学状态、概率、下一状态与格式化函数。
- `src/content.ts`：字幕与标签。
- `src/config/timeline.ts`：视频帧时间轴，450 帧即 15 秒。
- `src/config/style.ts`：颜色、字体。
- `src/scenes/ProbabilityBranch.tsx`：SVG 数学演示，使用视频帧决定动画。
- `scripts/check-math.ts`：遍历 16 个状态验证概率和、非法操作、数据不变性与两条历史汇合。

`topic` 只记录当前任务主题，不会替换数学计算或自动生成正确脚本。收到新题目后，应先调查、建模、写脚本和分镜，再更换场景与检验函数，不能仅把标题改成新题目。

源码还提供四张牌 A、Q、K、3 与两条历史 `A→Q` / `Q→A` 的计算。两者都剩 K、3；这个完整解释需要后续单独场景，未塞进本 15 秒片段。不同历史的等价性来自明确的均匀移除规则，不是所有现实过程都如此。

## 本地音乐与片段偏移

默认静音，没有附带第三方音乐。只有用户选定且可使用的音频才放入 `public/audio/`。在配置中填相对路径，例如 `audio/music.wav`。`offsetSeconds` 指该段对应的**原始音乐时间**，等于全片使用音乐的原始起始偏移加上当前段在全片的起点；例如全片从原音乐第 7 秒起配乐，全片 30 秒处的单段预览应填 37。如果已经裁成对应片段，应填 0，避免二次偏移。代码把秒数乘视频 fps 转成 `trimBefore` 所需的视频帧。不要使用音频分析帧索引代替视频帧。

实际读取音频并分析时长、估计拍点与段落，保存 `秒数` 和 `round(秒数×fps)`；无法确认重拍时要标为估计。数学阅读优先于卡点。可另用代码合成少量原创动作音效，先检查淡入淡出、叠加峰值和削波，不必每张牌都响。

## 交付前手动检查

渲染脚本会校验重复帧一致并读取编码后尺寸，但不会替你看画面或听音频。需实际检查开头、分支建立、概率出现、字幕切换、结尾；在手机尺寸检查中文、符号、边距与重叠。字体从系统中文字体回退，不打包商业字体；缺字时先安装可授权的中文字体。

`qa/render-check.json` 对手动观看、实际听审、实体手机播放默认写 false。完成后记录你真正做过的检查，不要把静态计算当作播放通过，也不要把静音浏览器截图当作听审。
